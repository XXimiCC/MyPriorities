# Демо-режим

> `?mock=1` — 45 дней синтетических данных в памяти. Без него проверить
> арифметику недельных и месячных окон можно только реально прождав месяц.

```
http://localhost:5173/?mock=1
```

## Что засевается

- **45 дней кликов** по семи приоритетам базового набора с заметным перекосом:
  «Работа» съедает почти всё, «Отдых» идёт следом. Ровно тот сюжет, ради которого
  приложение и построено.
- **Пара пропущенных дней** — чтобы серия и «активные дни» не были константой.
- **Переключения заряда** на каждый день.
- **Три навыка** на разных ступенях лестницы: «Гитара» (самостоятельный, большой
  стартовый капитал, дата начала 2014 года), «Программирование» (привязано к
  приоритету «Работа»), «Английский» (едва начатый).
- **Две отметки достижений** руками; остальные выдаёт обычная автоматика на этих
  же данных.

Генератор детерминированный: один и тот же прогон даёт одну и ту же картину.

## Чего в демо-данных нет

- **Ответов о том, что посадило заряд.** Переключения кладутся двухэлементными,
  без третьего поля. Раздел
  «[Что сажает батарею](/screens/stats#что-сажает-батарею)» в демо пуст, пока
  не ответить вручную.
- **Онбординга.** Демо-режим ставит отметку «пройден», поэтому первый запуск
  в нём недостижим — его снимают отдельным прогоном без `?mock`.
- **Архива** приоритетов и навыков.

## Запись отключена

::: warning
При включённом моке запись в хранилище отключена **целиком**: ни клики, ни
настройки, ни достижения никуда не уходят. Всё, что вы там накликаете, исчезнет
при перезагрузке.
:::

Это защита от единственного по-настоящему опасного сценария: синтетика,
уехавшая в облако поверх настоящей истории. Отката у такого не бывает.

Настройки в демо-режиме честно об этом пишут — приписка под кнопками сброса.

## Где это используется

- Ручная проверка окон в 7 и 30 дней.
- [Скриншоты для документации](/dev/screenshots): около сорока из пятидесяти
  трёх кадров сняты именно в этом режиме.
- Тест `src/domain/__mockcheck.test.ts` следит, чтобы генератор оставался
  согласованным.

::: details Как это работает внутри

- `src/store/mock.ts`. `MOCK_MODE` читается из строки запроса **один раз**, при
  загрузке модуля.
- Генератор — линейный конгруэнтный, сид `20260731`. Не `Math.random()`: одна и
  та же картина нужна и для глаза, и для скриншотов.
- Данные считаются **относительно текущей даты** (`addDays(now, -back)`), поэтому
  при съёмке скриншотов часы замораживаются — иначе даты на кадрах уезжали бы
  каждый прогон.
- Запись гасится не одним флагом, а ранним возвратом в каждой точке записи
  (`flush`, `writeSettings`, `writeSkills`, `writeAwards`) — так надёжнее, чем
  один общий предохранитель, который однажды забудут проверить.

:::
